# Surface brief: rea-brand report

Scope: the per-run report `brand.html`, built by `skills/rea-brand/report/build_report.py` from `brand.md`. Visitor mode: Read. Audience: skill users acting on a teardown, and X launch viewers seeing it in screenshots and screen recordings. Job: find the headline findings in seconds, trust them (SEEN / INFERRED, counts, links, bill), then copy a play.

Constraints: one self-contained HTML file (images base64), light and dark, desktop and phone, content varies per person (1 to 8+ platforms). Must not borrow the analyzed person's visual identity. Avoid: generic AI/SaaS glow, wall of text, flashy-over-trust.

## Direction contract

THESIS: An evidence report in the Stripe and Notion register: findings first, every number traceable. It refuses the dark glowing analytics dashboard and the undifferentiated doc wall.

OWN-WORLD: White paper ground, cool slate surfaces, navy ink, one confident blue for links and the active state. Evidence pills (SEEN green, INFERRED amber) are the only other colour. Inter with tabular figures; hairline rules; tables set like Stripe docs; prompts in quiet code panels.

STORY: The reader learns who was analysed, at what cost, and the five findings before scrolling; walks the sections by the sidebar; leaves with a play and its prompt copied.

FIRST VIEWPORT: 64px top bar (mark left, person and date right, theme toggle). 248px sticky sidebar contents with the active section marked. Main column: H1, meta line, a row of four evidence stat tiles, then the numbered short version at a 70ch measure.

FORM: The category standard, chosen by the user; quality bar Stripe and Notion; seed key c432e89e. Signature interaction: scroll-linked contents marker that slides to the section in view; copy-prompt confirms in place.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
